# 聚类算法

## 知识点定义

聚类算法是一类无监督学习方法，用于在没有标签的情况下，根据样本之间的相似性自动发现数据中的群组结构。

## 核心原理

常见聚类方法包括 K-Means、层次聚类和 DBSCAN。K-Means 通过迭代更新簇中心最小化样本到中心的距离，DBSCAN 则根据密度发现任意形状的簇并识别噪声点。

## 学习重点

- 理解无监督学习与监督学习的区别。
- 掌握 K-Means 的初始化、分配和更新步骤。
- 理解簇数 K 对结果的影响。
- 能使用轮廓系数等指标评价聚类结果。

## 常见误区

- 认为聚类结果一定等于真实类别。
- 忽略特征缩放对距离计算的影响。
- 随意选择 K 值，不做结果比较。
- 用单一指标判断聚类质量。

## 例题

为什么 K-Means 对初始中心敏感？

解析：不同初始中心会影响样本第一次分配，进而影响后续中心更新，最终可能收敛到不同的局部最优结果。

## 代码案例或伪代码

```python
from sklearn.cluster import KMeans

X = [[1, 2], [1, 3], [2, 2], [8, 8], [9, 8], [8, 9]]

model = KMeans(n_clusters=2, random_state=0, n_init=10)
labels = model.fit_predict(X)
print(labels)
print(model.cluster_centers_)
```

## 复习建议

先用二维数据画图观察簇结构，再运行 K-Means 比较不同 K 值结果。复习时注意距离度量、特征缩放和异常点影响。
