# 决策树

## 知识点定义

决策树是一种基于树结构进行分类或回归的机器学习模型。它通过不断选择特征进行划分，把样本分到不同叶子节点中，并在叶子节点给出预测结果。

## 核心原理

训练决策树时，需要选择能最好划分数据的特征。常见划分指标包括信息增益、信息增益率和基尼指数。树越深越容易拟合训练集，但也越容易过拟合。

## 学习重点

- 理解决策节点、分支、叶子节点的含义。
- 掌握信息熵、信息增益和基尼指数的直观意义。
- 能解释预剪枝和后剪枝的作用。
- 能分析决策树的可解释性优势。

## 常见误区

- 认为决策树越深越好，忽略过拟合风险。
- 混淆分类树和回归树的输出形式。
- 只看准确率，不观察树结构和特征重要性。
- 忽略连续特征需要选择划分阈值。

## 例题

如果某个特征划分后能让类别更纯，信息熵明显降低，这说明什么？

解析：说明该特征对区分类别有较强帮助，可能带来较高的信息增益。

## 代码案例或伪代码

```python
from sklearn.tree import DecisionTreeClassifier

X = [[0, 0], [1, 0], [1, 1], [0, 1]]
y = [0, 1, 1, 0]

model = DecisionTreeClassifier(max_depth=2, random_state=0)
model.fit(X, y)
print(model.predict([[1, 0]]))
```

## 复习建议

复习时画出一棵小树，标注每个节点使用的特征和判断条件。重点理解为什么某个特征适合作为当前划分依据。
