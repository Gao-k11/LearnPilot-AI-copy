# 支持向量机

## 知识点定义

支持向量机（SVM）是一种监督学习算法，常用于分类任务。它通过寻找一个最优超平面，使不同类别样本之间的间隔尽可能大。

## 核心原理

SVM 关注离分类边界最近的样本，这些样本称为支持向量。在线性不可分场景中，可以使用软间隔和核函数，把问题转化到更容易分类的空间。

## 学习重点

- 理解最大间隔分类思想。
- 掌握支持向量对分类边界的影响。
- 区分硬间隔、软间隔和核函数。
- 理解参数 C 与模型复杂度、误分类容忍度的关系。

## 常见误区

- 认为所有样本都同等决定分类边界，忽略支持向量的关键作用。
- 误以为核函数一定提升效果，忽略参数选择和数据规模。
- 混淆间隔最大化和训练准确率最大化。
- 不理解 C 过大可能导致过拟合。

## 例题

为什么 SVM 只关注靠近边界的少量样本？

解析：因为分类超平面的位置主要由支持向量决定，远离边界且分类正确的样本通常不会改变最优间隔。

## 代码案例或伪代码

```python
from sklearn.svm import SVC

X = [[1, 2], [2, 3], [3, 3], [8, 7], [9, 8], [10, 9]]
y = [0, 0, 0, 1, 1, 1]

model = SVC(kernel="linear", C=1.0)
model.fit(X, y)
print(model.predict([[4, 4]]))
```
