# 反向传播

## 知识点定义

反向传播是神经网络训练中的梯度计算方法。它基于链式法则，从损失函数开始，逐层向前面的参数计算梯度，用于指导参数更新。

## 核心原理

前向传播先计算模型输出和损失，反向传播再计算损失对每个参数的偏导数。优化器根据梯度和学习率更新参数，使损失逐步下降。

## 学习重点

- 理解计算图和链式法则。
- 能区分前向传播、反向传播和参数更新。
- 掌握学习率过大或过小带来的问题。
- 能用简单线性模型手算一次梯度。

## 常见误区

- 把反向传播等同于梯度下降，忽略二者职责不同。
- 只记公式，不理解梯度表示损失变化方向。
- 忽略激活函数导数对梯度传播的影响。
- 不理解梯度消失和梯度爆炸的成因。

## 例题

模型输出为 `y = wx`，损失为 `L = (y - t)^2`。求 `L` 对 `w` 的梯度。

解析：`dL/dw = 2(y - t) * dy/dw = 2(wx - t) * x`。

## 代码案例或伪代码

```python
w = 2.0
x = 3.0
t = 10.0
learning_rate = 0.01

y = w * x
loss = (y - t) ** 2
grad_w = 2 * (y - t) * x
w = w - learning_rate * grad_w

print(loss, grad_w, w)
```

## 复习建议

用一个只有一个参数的模型手算梯度，再逐步扩展到多层网络。每次训练时观察损失曲线，判断学习率是否合适。
