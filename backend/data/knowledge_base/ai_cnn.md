# CNN 卷积神经网络

## 知识点定义

CNN（Convolutional Neural Network，卷积神经网络）是一类适合处理图像、语音频谱、网格数据的深度学习模型。它通过卷积核在局部区域滑动，提取边缘、纹理、形状等层级特征。

## 核心原理

CNN 的核心由卷积层、激活函数、池化层和分类层组成。卷积层负责提取局部模式，激活函数引入非线性，池化层降低空间尺寸并增强鲁棒性，最后通过全连接层或全局池化完成分类或回归。

## 学习重点

- 理解卷积核、步幅、填充和特征图尺寸之间的关系。
- 掌握多通道输入与多卷积核输出的计算方式。
- 能解释池化层的作用和可能的信息损失。
- 能阅读一个简单 CNN 的 Python 代码结构。

## 常见误区

- 认为卷积核只能提取固定边缘，忽略卷积核参数是训练得到的。
- 混淆输入通道数、卷积核数量和输出通道数。
- 只会套公式计算尺寸，不理解步幅和填充对感受野的影响。
- 认为池化一定能提升效果，忽略任务和数据规模差异。

## 例题

输入图像尺寸为 32x32，卷积核大小为 3x3，步幅为 1，填充为 1，输出特征图尺寸是多少？

解析：输出尺寸为 `(32 - 3 + 2 * 1) / 1 + 1 = 32`，因此输出空间尺寸仍为 32x32。

## 代码案例或伪代码

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),
    nn.Flatten(),
    nn.Linear(16 * 16 * 16, 10),
)

x = torch.randn(4, 3, 32, 32)
y = model(x)
print(y.shape)
```
